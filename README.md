# Daily Task Scheduler

A simple, responsive daily task scheduler (to-do list) web application built with HTML, CSS, and JavaScript. This application is designed to be easily deployed on GitHub Pages.

## Features

- Add tasks with due dates and categories
- Mark tasks as complete
- Delete tasks
- Filter tasks by category and status
- Clear completed tasks or all tasks
- Task persistence using local storage
- Responsive design for mobile and desktop
- Light green theme with dark green buttons

## Files

- `index.html` - Main HTML structure
- `styles.css` - CSS styling with light green theme
- `script.js` - JavaScript functionality with local storage

## GitHub Pages Deployment Instructions

1. Create a new repository on GitHub
2. Upload all three files (`index.html`, `styles.css`, and `script.js`) to the repository
3. Go to repository Settings > Pages
4. Under "Source", select "main" branch
5. Click "Save"
6. Access site at `https://iosinnii.github.io/daily-task-scheduler/`

## Local Usage

Simply open the `index.html` file in any modern web browser to use the application locally.

## Browser Compatibility

This application is compatible with all modern browsers and is responsive for both desktop and mobile devices.
